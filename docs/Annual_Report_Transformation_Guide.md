Transform the current plain, text-heavy monthly performance reports generated by your Python-based automation engine into visually compelling, professionally designed annual reports that meet international standards and impress the Chairman and Board of Directors.

- **Visual Impact**: Move from table-heavy layouts to infographic-driven storytelling

- **Cultural Relevance**: Maintain Sinhala language excellence while incorporating modern design

### Expected Outcomes
- Chairman approval rating: 9/10 or higher
- Reduction in production time: From manual weeks to automated hours
- Stakeholder engagement: Increased readership and comprehension

## 5. Design System & Visual Language

### Color Palette

#### Primary Colors
**Navy Blue** (Authority & Trust)
- Hex: `#002366`
- RGB: `0, 35, 102`
- Usage: Headers, section dividers, primary buttons
- Represents: Government authority, stability, trust

**Coral/Orange** (Energy & Warmth)
- Hex: `#FF6B35`
- RGB: `255, 107, 53`
- Usage: Accent elements, call-outs, highlights
- Represents: Social warmth, human connection, vitality

#### Secondary Colors
**Teal** (Progress)
- Hex: `#00A8B5`
- RGB: `0, 168, 181`
- Usage: Digital transformation elements, growth metrics

**Green** (Success)
- Hex: `#2ECC71`
- RGB: `46, 204, 113`
- Usage: Positive metrics, achievement indicators

**Red** (Alerts)
- Hex: `#E74C3C`
- RGB: `231, 76, 60`
- Usage: Risk indicators, urgent items (sparingly)

#### Neutral Colors
**Charcoal** (Text)
- Hex: `#2C3E50`
- RGB: `44, 62, 80`
- Usage: Body text, descriptions

**Light Gray** (Backgrounds)
- Hex: `#F8F9FA`
- RGB: `248, 249, 250`
- Usage: Alternate section backgrounds, card backgrounds

**Medium Gray** (Borders)
- Hex: `#E9ECEF`
- RGB: `233, 236, 239`
- Usage: Dividers, table borders

**White** (Base)
- Hex: `#FFFFFF`
- Usage: Primary background, cards, clean space

### Color Usage Rules
1. **60-30-10 Rule**: 60% neutral (white/gray), 30% primary (navy), 10% accent (coral/teal)
2. **Section Color Coding**: Each major section gets subtle color identifier in header
3. **Data Visualization**: Use 4-color palette maximum per chart
4. **Accessibility**: Minimum 4.5:1 contrast ratio for all text
5. **Print Consideration**: All colors work in grayscale

---

### Typography System

#### Font Families

**Sinhala Text**
- Primary: `Noto Sans Sinhala` (Regular, Medium, Bold)
- Fallback: `Iskoola Pota`
- Character set: Complete Sinhala Unicode support
- Download from: Google Fonts (store locally)

**English Text**
- Primary: `Inter` (Light, Regular, Medium, Semibold, Bold)
- Alternative: `Roboto` if Inter unavailable
- Usage: English subtitles, numbers, technical terms

**Numbers & Data**
- Font: `Inter` or `Roboto`
- Reason: Clear legibility at all sizes, tabular figures

#### Typography Scale

**Display (Extra Large Numbers/Titles)**
- Size: 48-80pt
- Weight: Bold
- Usage: Cover page, key statistics, section numbers
- Example: "934.7M" on dashboard

**H1 (Section Titles)**
- Size: 24-32pt
- Weight: Bold
- Color: Navy Blue `#002366`
- Usage: Section divider pages, main headlines

**H2 (Sub-sections)**
- Size: 18-20pt
- Weight: Semibold
- Color: Charcoal `#2C3E50`
- Usage: Page titles, major subsections

**H3 (Components)**
- Size: 14-16pt
- Weight: Medium
- Usage: Card titles, table headers, chart titles

**Body Text**
- Size: 11pt
- Weight: Regular
- Line height: 1.6 (17.6pt)
- Color: Charcoal `#2C3E50`
- Usage: Paragraphs, descriptions, narratives

**Caption/Small**
- Size: 9pt
- Weight: Regular
- Color: Medium Gray
- Usage: Chart labels, footnotes, image captions

**Table Data**
- Size: 10pt
- Weight: Regular (Bold for headers)
- Tabular figures enabled

#### Typography Rules
1. **Maximum 3 font sizes** per page (excluding display numbers)
2. **Hierarchy through weight**, not just size
3. **Consistent spacing**: 1.5x font size for paragraph spacing
4. **Alignment**: Left-aligned for Sinhala text (natural reading)
5. **Line length**: 60-75 characters optimal (40-50 for Sinhala)
6. **Widow/Orphan control**: Enable in CSS

### Layout Grid System

#### Base Grid
- **12-column grid** for flexibility
- **Gutter width**: 20px between columns
- **Margin**: 
  - Left/Right: 30mm (minimum)
  - Top: 25mm
  - Bottom: 20mm (includes space for page numbers)

#### Page Layouts

**Layout A: Single Column (Text-Heavy)**
- 8 columns centered (4 empty columns total)
- Usage: Chairman's message, narratives
- Maximum width: 600px for readability

**Layout B: Two Column**
- 6 columns each
- Usage: Governance profiles, feature cards
- Equal weight content

**Layout C: Asymmetric (2:1)**
- 8 columns + 4 columns
- Usage: Image + caption, main content + sidebar

**Layout D: Three Column**
- 4 columns each
- Usage: Icon cards (like your uploaded image), value props

**Layout E: Dashboard Grid (2x2)**
- 6x6 columns per quadrant
- Usage: Performance dashboards, KPI grids

**Layout F: Full Bleed**
- Edge to edge content
- Usage: Section dividers, maps, large visualizations
- Text still respects margins

#### Spacing System
**Base unit: 8px**
- Micro spacing: 8px (elements within component)
- Small spacing: 16px (between related elements)
- Medium spacing: 24px (between components)
- Large spacing: 32px (between sections on page)
- Extra large: 48px (before major headers)

#### Responsive Considerations
Although PDF is fixed, design for:
- **A4 Portrait**: 210mm x 297mm (8.27" x 11.69")
- **Safe area**: Account for printer margins
- **Viewing on screen**: Ensure readability at 100% zoom

### Technologies to Add

#### For Enhanced CSS & Layout

**Tailwind CSS** (Recommended)
- **Purpose**: Utility-first CSS framework for rapid layout development
- **Why**: Speeds up development, ensures consistency
- **How to integrate**: 
  - Download standalone CSS file (3.x version)
  - Reference in HTML template
  - Use utility classes for spacing, colors, typography
- **Example utilities**: `grid-cols-3`, `p-6`, `text-2xl`, `bg-gray-50`
- **Customization**: Configure custom colors matching your palette
- **WeasyPrint compatibility**: Excellent (pure CSS)

**Alternative: Pure CSS Grid & Flexbox**
- **If avoiding frameworks**: Write custom CSS using CSS Grid and Flexbox
- **Benefit**: Complete control, smaller file size
- **Drawback**: More time to develop, need CSS expertise

**Recommendation**: Start with Tailwind for speed, optimize later if needed

#### For Charts & Visualizations

**Matplotlib** (Python)
- **Current usage**: Continue using
- **Enhancement**: Create custom style templates matching your color palette
- **Output**: High-resolution PNG (300 DPI for print quality)
- **Fonts**: Configure to use Noto Sans Sinhala

**Plotly** (Python)
- **Purpose**: Modern, beautiful charts with better defaults than Matplotlib
- **Why add**: Creates publication-quality charts with less code
- **Static export**: Use `fig.write_image()` to save as PNG
- **Sinhala support**: Set font family in layout
- **Chart types**: All types you need (donut, bar, line, etc.)

**Chart Generation Workflow:**
1. Data from pandas DataFrame
2. Create Plotly/Matplotlib figure
3. Apply custom theme (colors, fonts)
4. Export as PNG at 2x resolution (1600px width for full-width charts)
5. Save to assets folder
6. Reference in HTML template with `<img>` tag

#### For Icons & Graphics

**Heroicons** (SVG Icons)
- **Purpose**: Clean, modern icon set
- **Format**: SVG (perfect for print)
- **Usage**: Download needed icons, embed inline in HTML or reference as image
- **Style**: Outline or solid variants
- **License**: MIT (free for commercial use)
- **Alternative**: Phosphor Icons, Lucide Icons

**Custom SVG Creation** (If needed)
- **Tool**: Figma (free tier sufficient) or Inkscape (free, open-source)
- **Purpose**: Create custom icons matching your exact brand
- **Export**: SVG optimized for web

#### For QR Codes

**qrcode** (Python library)
- **Installation**: `pip install qrcode[pil]`
- **Purpose**: Generate QR codes programmatically
- **Usage**: Create QR for each section linking to digital content
- **Output**: PNG image
- **Customization**: Logo embedding, color schemes

#### For Advanced Image Processing

**OpenCV** (Optional, for face detection)
- **Purpose**: Auto-crop director photos to centered headshots
- **Face detection**: Locate face in image, crop to centered portrait
- **Use case**: When photos come in various compositions
- **Alternative**: Manual cropping if images are standardized

**Pillow (PIL)** (Already using)
- **Enhancement**: Add advanced features
  - Auto-contrast adjustment
  - Background removal (for product shots)
  - Circular masking for portraits
  - Watermarking

#### For Typography

**Google Fonts** (Download locally)
- **Fonts needed**:
  - Noto Sans Sinhala (Regular, Medium, Bold)
  - Noto Serif Sinhala (Optional for contrast)
  - Inter (Regular, Medium, Semibold, Bold)
- **Download**: Get TTF/OTF files
- **Storage**: Store in `assets/fonts/` folder
- **CSS**: Reference with `@font-face` declarations

**Font Subsetting** (Optimization)
- **Tool**: `pyftsubset` (from fonttools package)
- **Purpose**: Reduce font file size by including only used glyphs
- **Benefit**: Faster PDF generation, smaller file size

#### For Layout & Design Reference

**Figma** (Design Tool - Free tier)
- **Purpose**: Mock up page designs before coding
- **Workflow**:
  1. Design key page layouts in Figma
  2. Export specifications (spacing, colors, fonts)
  3. Implement in HTML/CSS
- **Benefit**: Visualize before building, easier stakeholder approval

**Browser Developer Tools**
- **Purpose**: Preview HTML before PDF generation
- **Workflow**: Serve HTML locally, inspect in browser, adjust CSS, regenerate PDF
- **Tools**: Chrome DevTools, Firefox Developer Edition

#### For PDF Optimization

**PyPDF2 or pikepdf** (Python)
- **Purpose**: Post-process generated PDF
- **Features**:
  - Add metadata (title, author, subject, keywords)
  - Compress images
  - Linearize for web viewing (fast web view)
  - Add security (password protection if needed)

### Performance Optimization Tips

**1. Image Optimization:**
- Resize before PDF generation (don't rely on CSS resize)
- Use appropriate format (PNG for logos/charts, JPG for photos)
- Compress without visible quality loss
- Target: <500KB per image

**2. Font Subsetting:**
- Include only glyphs actually used in report
- Can reduce font file from 500KB to 50KB
- Tool: `pyftsubset` from fonttools

**3. CSS Minimization:**
- Remove unused CSS rules
- Combine similar rules
- Use shorthand properties

**4. Chart Caching:**
- If data hasn't changed, reuse generated chart images
- Implement simple cache: filename based on data hash
- Saves regeneration time

**5. Parallel Processing:**
- Generate charts in parallel using multiprocessing
- Process images concurrently
- Can cut generation time by 30-50%

## Appendix C: Troubleshooting Guide

### Common Issues & Solutions

**Issue: Sinhala text appears as boxes or incorrect characters**
- **Cause:** Font not found or not properly embedded
- **Solution:** 
  - Verify font file path in CSS
  - Check font filename matches CSS declaration
  - Ensure font supports Sinhala Unicode range
  - Try different font (Noto Sans Sinhala is most reliable)

**Issue: PDF generation very slow (>2 minutes)**
- **Cause:** Large images, complex CSS, or too many pages
- **Solution:**
  - Optimize image sizes (resize, compress)
  - Simplify CSS (remove unused rules)
  - Profile with Python profiler to find bottleneck
  - Consider breaking into multiple PDFs if >100 pages

**Issue: Charts look pixelated or blurry**
- **Cause:** Image resolution too low
- **Solution:**
  - Generate charts at 2x size (1600px width minimum)
  - Set DPI to 300 when exporting
  - Use PNG format (not JPG) for charts
  - Check actual file size (should be >200KB for detailed chart)

**Issue: Page breaks in wrong places**
- **Cause:** WeasyPrint default page break algorithm
- **Solution:**
  - Add `page-break-inside: avoid` to containers
  - Add `page-break-after: always` to section dividers
  - Add `page-break-before: avoid` to elements that should stay with previous

**Issue: Colors look different in PDF than in browser**
- **Cause:** Color space differences (RGB vs CMYK)
- **Solution:**
  - Test print early and often
  - Adjust colors if needed for print
  - Use web-safe colors
  - Consider professional color calibration if critical

**Issue: Tables split across pages awkwardly**
- **Cause:** Table too long, no forced break
- **Solution:**
  - Add `page-break-inside: avoid` to table rows
  - Consider breaking large tables into smaller sections
  - Use `thead` element (repeats on each page)
  - Add manual page breaks between logical sections

**Issue: File size too large (>50MB)**
- **Cause:** Unoptimized images
- **Solution:**
  - Compress all images
  - Reduce chart resolution (but not below 300 DPI)
  - Remove unused embedded fonts
  - Consider PDF compression tools (Ghostscript)
